> **全面 PWA 化の注記（2026-07-07 決定）**

> 本ファイルの画面構成・ルート・操作対応表は**そのまま PWA に引き継ぐ**。「Wails Binding」は PWA では **LinkSelf TS 実装上のサービス層 API** に置き換わるため、下表の Binding 名・メソッドは移植時の**インタフェース契約**として読む。
> 下表「状態」列の実装状況は凍結時点の Wails 版のもの（= PWA への移植対象・移植順の参考）。

> **実装状況の注記（2026-07-01 onboard で実態と整合）**

> 現時点の実装状況は下表の「状態」列を参照。乖離の詳細は `concept.md §8` のドリフト論点を参照。

## 3. チェックアウト管理 `/checkouts`

### 位置づけと利用ロール

- **編集メンバー以上専用の管理画面**。サイドバーのこの項目は活動メンバーには非表示
- 編集メンバー以上が複数のチェックアウトを俯瞰し、貸出発行・強制回収・担当者変更・招待管理など **管理操作** を集中的に行う場所
- **活動メンバーは本画面にはアクセスせず**、自分が関与するチェックアウト区域への入口は **ダッシュボード** の「アクセス可能な区域」セクションを使う
- 編集メンバー以上が「自分が現場で記録したい」目的で訪問記録画面へ入る場合も、本画面ではなくダッシュボードの「全ての区域一覧」を起点とする（責務分担の明確化）

### 画面構成

```
┌──────────────────────────────────────────────────────┐
│ チェックアウト                       [+ チェックアウト] │
├──────────────────────────────────────────────────────┤
│ [活動中] [返却済み] [完了] [強制クローズ] [検索: ____] │
├──────────────┬───────────────────────────────────────┤
│ 一覧          │ 詳細                                   │
│              │                                       │
│ ▸ NRT-001-01 │ 区域: NRT-001-01 加良部1丁目-01        │
│   活動中      │ 担当者: 田中太郎                       │
│   田中太郎    │ 操作実行者: 鈴木編集                   │
│              │ 期間: 2026春期キャンペーン              │
│ ▸ NRT-001-02 │ ステータス: 活動中                      │
│   活動中      │ 開始: 2026-03-01                      │
│   鈴木次郎    │                                       │
│              │ ─── 訪問記録 ───                        │
│ ▸ NRT-002-01 │ 12件 (会えた: 8, 留守: 4)               │
│   返却済み    │                                       │
│   佐藤三郎    │ ─── 招待 ───                            │
│              │ 佐藤花子   残22h   [取消]                │
│              │ 高橋一郎   残14h   [取消]                │
│              │ [+ 招待を発行]                           │
│              │                                       │
│              │ [返却] [強制回収] [担当者変更]           │
└──────────────┴───────────────────────────────────────┘
```

- 「招待」セクションは active チェックアウトでのみ表示。返却済み・完了済み・強制クローズ済みは過去履歴として残時間欄に「失効」と表示
- 「+ 招待を発行」ボタンで招待発行ダイアログを開く（仕様は `05_チェックアウト.md` の「招待 UI」節）
- 「期間」欄は当該チェックアウトが属する AvailablePeriod の名前を表示
- アクティブな AvailablePeriod がない時期は「+ チェックアウト」ボタンが非活性、「現在チェックアウト可能期間がありません」と案内

### 操作 → Binding対応

| 操作 | Service メソッド | ロール制限 |
|---|---|---|
| チェックアウト発行（+ ボタン） | `CheckoutService.Checkout` | editor+（任意のメンバーを担当者にできる）／活動メンバーは自分のみ担当者可 |
| 返却 | `CheckoutService.Return` | 担当者 |
| 強制回収 | `CheckoutService.ForceReturn` | editor+ |
| 担当者変更 | `CheckoutService.ReassignPersonInCharge` | editor+ |
| 招待発行 | `CheckoutService.Invite` | editor+ または当該チェックアウト担当者 |
| 招待取消 | `CheckoutService.RevokeInvite` | 招待者本人／現担当者／editor+ |
| 招待一覧 | `CheckoutBinding.ListInvitations(checkoutID)` | all（閲覧） |
| ステータスタブ切替 | `CheckoutBinding.ListCheckouts(filter)` | all |
| 詳細表示 | `CheckoutBinding.GetCheckout` + `ListVisitRecords` + `ListInvitations` | all |

### チェックアウトダイアログ

```
┌─── チェックアウト発行 ─────────────────┐
│                                      │
│ 期間:     2026春期キャンペーン (固定)   │
│ 区域:     [区域選択ピッカー ▾]         │
│ 担当者:   [自分] [メンバー選択 ▾]      │
│                                      │
│       [キャンセル]  [チェックアウト]    │
└──────────────────────────────────────┘
```

- 期間表示
  - 現在アクティブな AvailablePeriod 名を固定表示（編集不可）
  - クールダウン期間中はダイアログ自体を開けない
- 区域選択
  - 既存の AreaPickerDialog を流用。チェックアウト済みの区域はグレーアウト
  - **アクティブ AvailablePeriod の対象区域親番配下のみ選択可能**（活動メンバー・編集メンバー以上ともに同じ制約）
  - 対象外の区域を扱いたい場合は、編集メンバーが `/coverage` で AvailablePeriod の対象区域親番リストに追加する
- 担当者選択
  - **クイック候補「自分」を最上位に常設**
  - 編集メンバー以上: 通常のメンバー選択ピッカーから他メンバーを指定することも可能
  - 活動メンバー: 自分のみ選択可能（他メンバー指定 UI は非表示）
- 起動経路と既定値
  - `/checkouts` の「+ チェックアウト」ボタンから起動：区域・担当者ともに未確定
  - ダッシュボードの「チェックアウト可能な区域」セクション行ボタンから起動：**区域は固定モード**、担当者は「自分」固定
  - 訪問記録画面の「この区域をチェックアウトして記録する」CTA から起動：**区域は固定モード**、担当者は「自分」を既定選択

## 4. メンバー・タグ管理 `/users`

### 位置づけと利用ロール

- **管理者専用画面**。サイドバーのこの項目は編集メンバー・活動メンバーには非表示
- ロール任免（招待・罷免）とタグ管理を含むメンバー全般の管理を行う（メンバーグループ／OrgGroup 概念は廃止済み。分類はロール＋メンバータグで表現）
- **実装状況**: 現状はタグ管理のみ本実装。ロール任免（招待・罷免・ユーザー作成）UI は未実装（ロジックは `AuthService` に存在、binding/UI が未配線 → `concept.md §8 論点-006`）
- 編集メンバーはメンバー管理権限を持たない。タグ等は管理者が一任した運用で代替する（タグ管理 UI は将来管理者専用画面内に集約する）

### 画面構成

```
│  佐藤三郎    編集      ベテラン           2025/04/03 │
```

- メンバーグループ（OrgGroup）概念は廃止。「Aチーム」のような分類が必要な場合はメンバータグで運用する

### 操作 → Binding対応

`/users` ページ自体が管理者専用なので、以下はすべて admin が前提。サービス層では引き続き actor のロール検証を行う（API 直叩き対策）。

| 操作 | Service メソッド | ロール制限 |
|---|---|---|
| メンバー一覧表示 | `UserBinding.ListUsers` | admin |
| タグ管理（メンバータグ） | `UserBinding.SaveTag` / `DeleteTag` | admin |
| メンバーへのタグ付与 | `UserBinding.SaveUser` | admin |
| ロール任命招待 | `AuthService.InviteToRole` | admin |
| メンバー削除 | `AuthService.RemoveMember` | admin |
| ロール罷免 | `AuthService.DismissRole` | admin |
| 招待一覧 | `UserBinding.ListInvitations` | editor+ |

## 5. ダッシュボード `/`

### 画面構成

```
┌──────────────────────────────────────────────────────┐
│ ダッシュボード                                        │
├──────────────────────────────────────────────────────┤
│ 現在の期間: 2026春期キャンペーン (3/1 - 4/30)         │
│                                                      │
│ ─── 通知 (3件未読) ───                                │
│ 🔵 区域NRT-001-05がチェックアウトされました 3時間前    │
│ 🔵 佐藤さんが区域NRT-002-01を返却しました   6時間前     │
│ ○  高橋さんの任命招待が受理されました      昨日        │
│                                                      │
│ ─── アクセス可能な区域 ───                              │
│ （担当しているチェックアウト + 有効な招待区域）          │
│  区域          ロール        進捗                      │
│  NRT-001-01 🔑担当者       ████░░ 67% [訪問記録 →][招待]│
│  NRT-001-02 🕒招待(残22h)  ██░░░░ 33% [訪問記録 →]     │
│                                                      │
│ ─── チェックアウト可能な区域 ───                        │
│ （アクティブ期間の対象区域親番配下、未チェックアウトのみ）│
│  NRT-001-03  -            [チェックアウト]            │
│  NRT-001-04  -            [チェックアウト]            │
│                                                      │
│ ─── 全ての区域一覧 (編集メンバー以上のみ) ───            │
│  [領域 ▾] [区域親番 ▾]                [検索: ______]  │
│  NRT-001-01  田中太郎(担当)  ████░░ 67%   [訪問記録 →]│
│  NRT-001-02  鈴木次郎(担当)  ██░░░░ 33%   [訪問記録 →]│
│  NRT-001-03  未チェックアウト  -            [訪問記録 →]│
│  ...                                                 │
│                                                      │
│ ─── 網羅進捗サマリー ───                               │
│  成田市  加良部1: 45%  加良部2: 30%  囲護台: 60%      │
│  富里市  七栄: 20%  日吉台: 15%                       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- 画面上部に **現在のアクティブな AvailablePeriod** 名と期間を表示。クールダウン期間中は「現在チェックアウト可能期間がありません」と表示し、「チェックアウト可能な区域」セクションを非表示にする
- 「チェックアウト可能な区域」セクションは全ロール共通で表示する活動メンバーの主動線
  - 活動メンバー: 自分自身を担当者としたチェックアウトを発行
  - 編集メンバー以上: 同じセクションから自分にチェックアウト可能（「全ての区域一覧」セクションは閲覧・他者割当用途として並存）
  - クールダウン期間中はセクション内容を空にし「現在チェックアウト可能期間がありません」と案内

- 「訪問記録 →」ボタンで当該区域の訪問記録画面（地図主体）へ遷移する。これが訪問記録画面への唯一の入口（左サイドバーには独立メニューを設けない）
- 「アクセス可能な区域」セクションに含まれる区域（**入力可能**な区域）
  - 自分が担当者となっているアクティブなチェックアウト
  - 自分が有効な招待を受けている他者のチェックアウト（`05_チェックアウト.md` の区域招待）
- ロール表記
  - **担当者**: 「鍵」アイコン＋テキスト「担当者」
  - **被招待者**: 「人＋時計」アイコン＋テキスト「招待 (残 N h)」（残時間はテキストで明示）
  - 色だけに頼らずアイコン形状で区別する（色覚多様性への配慮）。誤操作防止のため、被招待者行では「返却」「強制回収」操作を非表示／非活性とする
- 行内操作
  - **担当者行**: 「訪問記録 →」「招待」ボタン。「招待」ボタンで招待発行ダイアログ（`05_チェックアウト.md` の招待 UI 節）を開ける。これは活動メンバーが `/checkouts` にアクセスせず自分のチェックアウトに招待を出すための経路
  - **被招待者行**: 「訪問記録 →」のみ
- 進捗バーの値
  - 各行の進捗バーは **網羅管理（`06_網羅管理.md`）の区域単位完了パーセンテージのエイリアス表示**
  - 値の計算ロジック・更新タイミング・「会えた」「留守」等の重み付けはすべて網羅管理側の仕様に従う
  - ダッシュボードは独自の進捗計算は持たず、`CoverageBinding` 経由で網羅管理の値を参照する（情報の単一ソース化）
  - **対象期間は「現在時刻が含まれるアクティブな AvailablePeriod（チェックアウト可能期間）」を一律使用する**
    - 活動メンバーがアクセス可能な区域は自分が担当・招待を受けているものに限定されるため、アクティブ期間内のすべての進捗が自然に「自分のスコープ内」に収まる
    - 編集メンバーが「全ての区域一覧」で見る場合も、同じくアクティブ AvailablePeriod の進捗を表示（直近の活動状況に集中）
    - アクティブな AvailablePeriod が存在しない時期（クールダウン期間）は進捗バーを「-」で表示し、過去履歴は網羅管理画面で参照する役割分担とする
- 「全ての区域一覧」セクション
  - 編集メンバー以上のみに表示する（活動メンバーには非表示）
  - **閲覧** はチェックアウト不要で全区域可能（上位互換）
  - **入力** には当該区域への active チェックアウトが必要。入力したい場合は訪問記録画面遷移後に「この区域をチェックアウトして記録する」誘導 CTA からチェックアウトを行う（詳細は `05_チェックアウト.md` の「入力動線」節）
  - 領域・区域親番フィルタ／検索で絞り込み可能

### 操作 → Binding対応

| 操作 | Binding | 備考 |
|---|---|---|
| 現在の AvailablePeriod 取得 | `CoverageBinding.GetActiveAvailablePeriod` | アクティブ判定はサーバ側で `now` 基準 |
| 通知一覧 | `NotificationBinding.ListNotifications(myDID)` | 未読優先 |
| 通知既読 | `NotificationBinding.MarkRead` | クリック時 |
| アクセス可能な区域 | `CheckoutBinding.ListAccessibleAreas(myDID)` | 担当者+有効招待を統合 |
| チェックアウト可能な区域 | `CheckoutBinding.ListCheckoutableAreas(myDID)` | アクティブ AvailablePeriod の対象区域親番配下、自分が未チェックアウト・他者アクティブなし |
| チェックアウト発行 | `CheckoutService.Checkout` | 全ロール（活動メンバーは自分担当のみ） |
| 担当者行から招待発行 | `CheckoutService.Invite` | 担当者本人 |
| 全ての区域一覧 | `RegionBinding.ListAreas(filter)` | editor+ のみ |
| 訪問記録画面へ遷移 | ルート `/visits/:areaId` | 全ロール（アクセス権チェックは画面側） |
| 網羅進捗 | `CoverageBinding.ListCoverages` | 全領域のサマリー |

## 6. 網羅管理 `/coverage`（AvailablePeriod 管理＋進捗参照）

### 位置づけ

- AvailablePeriod（チェックアウト可能期間）の作成・編集・削除と、選択した期間の網羅進捗参照を統合した画面
- 過去・現在・未来の AvailablePeriod を切り替えて参照できる
- 編集メンバー以上のみ編集可、活動メンバーは閲覧のみ（活動メンバーには進捗確認用の簡易ビュー）

### 画面構成

```

│ タグ: [春期] [強化エリア]    [タグで絞込 ▾]           │
├───────────────┬──────────────────────────────────────┤
```

- 上部の期間ピッカーで AvailablePeriod を切り替え（過去・現在・未来）
- タグフィルタで AvailablePeriod を絞り込んで一覧表示
- 過去 AvailablePeriod 選択時は「過去記録モード」（編集不可、参照のみ）

### AvailablePeriod 編集ダイアログ

```
┌─── チェックアウト可能期間の編集 ────────┐
│                                       │
│ 名前:        [2026春期キャンペーン]    │
│ 開始日:      [2026-03-01]             │
│ 終了日:      [2026-04-30]             │
│ タグ:        [春期 ✕] [強化エリア ✕]   │
│              [+ タグ追加]              │
│ 対象区域親番:                          │
│   ☑ 加良部1丁目                       │
│   ☑ 加良部2丁目                       │
│   ☑ 囲護台                            │
│   ☐ 赤坂                              │
│   ...                                 │
│                                       │
│       [キャンセル]  [保存]              │
└───────────────────────────────────────┘
```

- 開始前: 全項目編集可
- 活動中: 終了日延長・対象区域親番追加・タグのみ編集可（短縮・削除は無効化）
- 終了後: タグのみ編集可（その他は読み取り表示）
- 削除ボタンは開始前のみ活性（活動中・終了後は監査保全のため非活性）
- 保存時は監査ログに変更内容を記録

### 操作 → Binding対応

| 操作 | Binding | ロール制限 |
|---|---|---|
| AvailablePeriod 一覧 | `CoverageBinding.ListAvailablePeriods(filter)` | all |

| AvailablePeriod 作成 | `CoverageBinding.SaveAvailablePeriod` | editor+ |
| AvailablePeriod 編集 | `CoverageBinding.SaveAvailablePeriod`（編集制約はサービス層） | editor+ |
| AvailablePeriod 削除 | `CoverageBinding.DeleteAvailablePeriod` | editor+ ／ 開始前のみ |
| AvailablePeriod タグ管理 | `CoverageBinding.SaveAvailablePeriodTag` / `DeleteAvailablePeriodTag` | editor+ |
| 網羅進捗 | `CoverageBinding.ListCoverages(periodId)` | all |
| 区域別進捗 | `CoverageBinding.ListAreaProgress(periodId)` | all |
