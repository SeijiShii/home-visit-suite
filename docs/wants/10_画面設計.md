## 区域一覧 `/areas`（2026-07-16 新設）

### 位置づけと利用ロール

- **編集メンバー以上専用**。サイドバーに独立項目を持つ（活動メンバーには非表示）
- 区域親番を起点に全区域のチェックアウト状況を俯瞰し、その場で担当者の割り当て・回収・招待管理を行う管理画面
- **チェックアウト管理 `/checkouts` を置き換えた**（2026-07-16 廃止。移管内容は §3 の廃止記録を参照）
- ダッシュボードの「全ての区域一覧」セクションは本画面へ移管して廃止（編集メンバー以上の訪問記録入口も本画面が引き継ぐ）

### 画面構成

- **区域親番の一覧テーブル**を表示する。テーブル行（親番）を展開すると配下の**区域**が見える
  - 親番行: 親番 ID（例: `NRT-001`）・名称・配下区域数
  - 親番は **ID や名称で絞り込み**できる（検索入力）
- **区域行**の表示内容:
  - 区域 ID（例: `NRT-001-05`）
  - チェックアウト中なら**担当メンバー名とチェックアウト日付**
  - チェックアウト可能な状態（アクティブなチェックアウトが無い × ポリゴン紐付け済み）なら**チェックアウトボタン**を表示
  - ポリゴン未紐付けの区域はチェックアウト不可の旨を表示（ボタンなし）
  - 「訪問記録 →」で当該区域の訪問記録画面へ遷移できる（旧ダッシュボード「全ての区域一覧」の入口を引き継ぐ）
  - **チェックアウト中の区域行**には「招待」「回収」ボタンを表示する（2026-07-16 チェックアウト管理廃止に伴う移管）
- **チェックアウトボタン押下 → 担当者の割り当て**:
  - 担当者選択ダイアログを開く（クイック候補「自分」＋メンバー選択。区域は行から固定）
  - 確定で `CheckoutService.Checkout`（editor+ は任意メンバーを担当者にできる）を実行し、行の表示を更新する
- **「招待」ボタン → 招待管理ダイアログ**（`05_チェックアウト.md`「招待 UI」）:
  - 既発行招待の一覧（被招待者名・残り時間・状態）と取消、新規発行を 1 つのダイアログで行う
  - editor+ が他メンバーのチェックアウトへ代理で招待を発行・取消する経路（担当者本人の経路はダッシュボード）
- **「回収」ボタン → 強制回収**:
  - 確認ダイアログを挟み `CheckoutService.ForceReturn` を実行する（紐づく未失効招待も一括失効）
  - 返却しないまま放置された区域を editor+ が解放する安全弁。担当者本人の通常返却はダッシュボードから行う

### 操作 → Binding対応

| 操作 | Service メソッド | ロール制限 |
|---|---|---|
| 親番/区域ツリー取得 | `RegionBinding.List*` | editor+ |
| 区域のチェックアウト状況 | `CheckoutBinding.GetActiveCheckout(areaId)` | editor+ |
| チェックアウト割り当て | `CheckoutService.Checkout(actor, areaId, personInCharge)` | editor+ |
| 回収 | `CheckoutService.ForceReturn` | editor+ |
| 招待一覧 | `CheckoutBinding.ListInvitations(checkoutID)` | editor+ |
| 招待発行 | `CheckoutService.Invite` | editor+ |
| 招待取消 | `CheckoutService.RevokeInvite` | 招待者本人／現担当者／editor+ |
| 訪問記録画面へ遷移 | ルート `/visits/:areaId` | editor+ |

## 3. チェックアウト管理 `/checkouts`（廃止）

> **2026-07-16 廃止・削除。** 区域一覧 `/areas`（#13）の確立に伴い本画面は削除した。旧 UI 実装は git 履歴から復元可能。機能の移管・廃止内訳:
>
> - **チェックアウト発行**（editor+ が任意メンバーを担当者に指定）→ 区域一覧 `/areas` の割り当てダイアログへ移管
> - **回収（強制回収）** → 区域一覧 `/areas` のチェックアウト中区域行「回収」へ移管
> - **招待の一覧・取消・発行** → 招待管理ダイアログに集約し、アクセス経路は 2 つ: ①担当者本人はダッシュボード「アクセス可能な区域」の「招待」、②editor+ は区域一覧 `/areas` のチェックアウト中区域行「招待」（`05_チェックアウト.md`「招待 UI」）
> - **返却済み・完了チェックアウトの履歴閲覧**は**廃止**（受け皿は将来の網羅管理 `/coverage` 再構築時に検討。`06_網羅管理.md`）
> - **担当者変更（ReassignPersonInCharge）の UI** は**廃止**（回収→再割り当てで代替。サービス API は残置）
> - **担当者名での検索・全チェックアウトの時系列一覧**は**廃止**（区域一覧の親番絞り込みで代替）

## 4. メンバー・タグ管理 `/users`

### 位置づけと利用ロール

- **管理者専用画面**。サイドバーのこの項目は編集メンバー・活動メンバーには非表示
- メンバーの編集（表示名・ロール直接変更）・削除とタグ管理を含むメンバー全般の管理を行う（メンバーグループ／OrgGroup 概念は廃止済み。分類はロール＋メンバータグで表現。任命招待フローは 2026-07-14 廃止 → `04` 「任免」）
- **グループ名の変更**セクションを持つ（`04` 「グループ名」。管理者がいつでも変更でき、以後発行する招待 URL に反映される）
- **グループ招待の発行**セクションでは発行時に参加ロール（管理者・編集メンバー・活動メンバー、既定は活動メンバー）を選択できる（`04` 「グループ招待」）
- 編集メンバーはメンバー管理権限を持たない。タグ等は管理者が一任した運用で代替する（タグ管理 UI は将来管理者専用画面内に集約する）

- メンバーグループ（OrgGroup）概念は廃止。「Aチーム」のような分類が必要な場合はメンバータグで運用する

### メンバーの編集・削除（行アクション）

- メンバー一覧の各行に**編集**・**削除**ボタンを置く（`04` 「任免（メンバーの編集と削除）」）
- 編集モーダル: 表示名の入力とロールの選択。**自分自身の行ではロール選択を無効化**する（自己ロール変更不可）
- 削除確認モーダル: 対象の表示名を示して確認する。**自分自身の行では削除ボタンを表示しない**
- 旧「招待」タブ（保留中の任命招待一覧）は**任命招待フローの廃止（2026-07-14）に伴い廃止**

### 操作 → Binding対応

`/users` ページ自体が管理者専用なので、以下はすべて admin が前提。サービス層では引き続き actor のロール検証を行う（API 直叩き対策）。

| 操作 | Service メソッド | ロール制限 |
|---|---|---|
| メンバー一覧表示 | `UserBinding.ListUsers` | admin |
| タグ管理（メンバータグ） | `UserBinding.SaveTag` / `DeleteTag` | admin |
| メンバーへのタグ付与 | `UserBinding.SaveUser` | admin |
| メンバー編集（表示名・ロール） | `AuthService.UpdateMember` | admin |
| メンバー削除 | `AuthService.RemoveMember` | admin |

### 画面構成

```
┌──────────────────────────────────────────────────────┐
│ ダッシュボード                                        │
├──────────────────────────────────────────────────────┤

│ ○  高橋さんの任命招待が受理されました      昨日        │
│                                                      │
│ ─── アクセス可能な区域 ───                              │
│ （担当しているチェックアウト + 有効な招待区域）          │

│ ─── チェックアウト可能な区域 (活動メンバーのみ) ───      │
│ （未チェックアウトの区域。編集メンバー以上は /areas へ） │
│  NRT-001-03  -            [チェックアウト]            │
│  NRT-001-04  -            [チェックアウト]            │

│  富里市  七栄: 20%  日吉台: 15%                       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- 「チェックアウト可能な区域」セクションは**活動メンバーのみ**に表示する（2026-07-16 変更。編集メンバー以上はダッシュボードでは表示せず、区域一覧 `/areas` から割り当てる）
  - 他者のアクティブなチェックアウトが無い区域を候補として表示する
  - 活動メンバー: 自分自身を担当者としたチェックアウトを発行
  - 候補が無いときはセクション内容を空にし「チェックアウト可能な区域はありません」と案内
- 「全ての区域一覧」セクションは**廃止**（2026-07-16。区域一覧 `/areas` へ移管。編集メンバー以上の訪問記録入口も同画面が引き継ぐ）

- 「訪問記録 →」ボタンで当該区域の訪問記録画面（地図主体）へ遷移する。これが訪問記録画面への唯一の入口（左サイドバーには独立メニューを設けない）
- 「アクセス可能な区域」セクションに含まれる区域（**入力可能**な区域）
  - 自分が担当者となっているアクティブなチェックアウト
  - 自分が有効な招待を受けている他者のチェックアウト（`05_チェックアウト.md` の区域招待）
- ロール表記
  - **担当者**: 「鍵」アイコン＋テキスト「担当者」
  - **被招待者**: 「人＋時計」アイコン＋テキスト「招待 (残 N h)」（残時間はテキストで明示）
  - 色だけに頼らずアイコン形状で区別する（色覚多様性への配慮）。誤操作防止のため、被招待者行では「返却」「強制回収」操作を非表示／非活性とする
- 行内操作
  - **担当者行**: 「訪問記録 →」「招待」「返却」ボタン。
    - 「招待」ボタンで**招待管理ダイアログ**（`05_チェックアウト.md` の招待 UI 節）を開ける。既発行招待の一覧・残り時間・取消と新規発行を行う。担当者本人が自分のチェックアウトの招待を管理する経路（もう一方の経路は editor+ の区域一覧 `/areas`。2026-07-16 チェックアウト管理廃止に伴い改訂）
    - 「返却」ボタンで当該チェックアウトを返却する（`05_チェックアウト.md`「返却と回収」）。誤操作防止のため確認ダイアログを挟む。返却後は当該区域が「アクセス可能な区域」から外れ、「チェックアウト可能な区域」に戻る
  - **被招待者行**: 「訪問記録 →」のみ（返却・強制回収は不可）
- 進捗バーの値
  - 各行の進捗バーは **網羅管理（`06_網羅管理.md`）の区域単位完了パーセンテージのエイリアス表示**
  - 値の計算ロジック・更新タイミング・「会えた」「留守」等の重み付けはすべて網羅管理側の仕様に従う
  - ダッシュボードは独自の進捗計算は持たず、`CoverageBinding` 経由で網羅管理の値を参照する（情報の単一ソース化）
  - **進捗は全期間で集計する**（期間による母集団の区切りは持たない。`06_網羅管理.md`「区域単位の進捗指標」参照）
- 「全ての区域一覧」セクション
  - 編集メンバー以上のみに表示する（活動メンバーには非表示）
  - 閲覧・**訪問記録の入力・修正ともにチェックアウト不要**で全区域可能（2026-07-14 改訂。編集メンバー以上は他メンバーの誤登録を是正する権限を持つため。`08_活動メンバー向けアプリ.md`「区域」）
  - 領域・区域親番フィルタ／検索で絞り込み可能

### 操作 → Binding対応

| 操作 | Binding | 備考 |
|---|---|---|
| 通知一覧 | `NotificationBinding.ListNotifications(myDID)` | 未読優先 |
| 通知既読 | `NotificationBinding.MarkRead` | クリック時 |
| アクセス可能な区域 | `CheckoutBinding.ListAccessibleAreas(myDID)` | 担当者+有効招待を統合 |
| チェックアウト可能な区域 | `CheckoutBinding.ListCheckoutableAreas(myDID)` | 活動メンバーのみ表示（2026-07-16） |
| チェックアウト発行 | `CheckoutService.Checkout` | 活動メンバー（自分担当のみ）。editor+ は `/areas` から |
| 担当者行から返却 | `CheckoutService.Return` | 担当者本人 |
| 担当者行から招待発行 | `CheckoutService.Invite` | 担当者本人 |
| 担当者行から招待一覧・取消 | `CheckoutBinding.ListInvitations` / `CheckoutService.RevokeInvite` | 担当者本人（取消は招待者本人／現担当者／editor+） |
| 訪問記録画面へ遷移 | ルート `/visits/:areaId` | 全ロール（アクセス権チェックは画面側） |
| 網羅進捗 | `CoverageBinding.ListCoverages` | 全領域のサマリー |
