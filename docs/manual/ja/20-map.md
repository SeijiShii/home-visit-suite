地図上にポリゴンを描いて区域の範囲を決め、区域と紐づける画面です（{{route:/map}}）。編集メンバー以上が使います。
画面の幅が狭い端末（スマートフォンなど）では表示されません。

{{shot:map-overview|左が地図、右が「区域」「ポリゴン」の一覧}}

## 画面の見かた

左が地図、右が一覧です。一覧は「区域」と「ポリゴン」の 2 つのタブに分かれています。

- 「区域」タブ … 領域 → 区域親番 → 区域のツリーです。▶ / ▼ で開閉します。区域の行をクリックすると、その区域のポリゴンが地図の中央に表示されます
- 「ポリゴン」タブ … 地図上のポリゴンの一覧です。描画・紐づけ・表示の切り替えはここから行います

一覧と地図の境目を左右にドラッグすると、一覧の幅を変えられます。「一覧を閉じる」（▶）を押すと一覧がたたまれて地図が全幅に広がり、「一覧を開く」（◀）で戻せます。

地図の右上には「現在地へ移動」があり、押すと現在地へ移動します。位置情報の利用を許可していない場合は、このとき許可を求められます。

この画面を開いた直後、ポリゴン操作のヒントが画面の右上に順に表示されます。不要になったヒントは「このメッセージを表示しない」を押すと以後表示されなくなります。

## ポリゴンを描く

1. 「ポリゴン」タブを開き、上部の鉛筆ボタン（「描画開始」）を押します。
2. 地図をクリックして頂点を順に置きます。画面には「地図をクリックして頂点を追加。始点付近クリックで閉じます。」と表示されます。
3. 始点をクリックするとポリゴンが閉じて確定します。
4. 直前の頂点を取り消すときは「戻す」を押します。地図上での右クリックでも同じことができます。
5. 閉じずに描画をやめるときは「描画終了」を押します。

描画中のクリックは既存のポリゴンに吸い付きます。既存の頂点の近くをクリックするとその頂点をそのまま使い、既存の辺の近くをクリックするとその辺を分割して頂点を作ります。隣り合う区域どうしで境界線を共有したいときは、この操作で描き始めたり描き終えたりします。

ほかのポリゴンを編集している間は「描画開始」は押せません。先に「編集完了」で編集を終えてください。

{{shot:map-drawing|描画中に表示されるツールバー}}

## ポリゴンの形を直す

ポリゴンの内部をクリックすると編集モードに入り、「頂点をドラッグして編集。地図の空白クリックまたは「編集完了」で終了。」と表示されます。

- 頂点をドラッグすると形が変わります
- 辺を右クリックすると「頂点の追加」が出ます
- 頂点を右クリックすると「頂点を削除」が出ます

編集を終えるときは「編集完了」を押すか、地図の何もないところをクリックします。

頂点をほかの頂点に近づけると吸い寄せられ、そのまま離すと 2 つの頂点が 1 つにまとまります。このとき面がなくなってポリゴンが消える場合は「この操作によりポリゴンが削除されます。よろしいですか？」と確認が出ます。「削除する」で確定、「キャンセル」でドラッグ前の状態に戻ります。

ロック中のポリゴンは、クリックしても編集モードに入りません（選択されて地図が寄るだけです）。形を直すには先にロックを外してください。

## 元に戻す・やり直す

地図の左下に「元に戻す」「やり直す」のボタンがあります。ポリゴンの編集操作をさかのぼったり、やり直したりできます。戻せる操作がないときはボタンが薄い表示になります。描画中はこのボタンは出ません（描画ツールバーの「戻す」を使います）。

いったん確定した削除を「元に戻す」で戻した場合、ポリゴンの形は元に戻りますが、削除にともなって外れた区域との紐づけは戻りません。必要なら紐づけ直してください。

## ポリゴンを区域と紐づける

「ポリゴン」タブの各行の左側には、そのポリゴンに紐づいている区域が表示されます。紐づいていなければ「区域なし」、1 つなら区域 ID と区域親番名（例: NRT-001-05 加良部1丁目）、2 つ以上なら「複数の区域」と表示されます。

1. 紐づけたいポリゴンの行の ➕（「区域と紐づけ」）を押します。
2. 「紐づける区域を選択」が開くので、ツリーをたどって区域を選びます。
3. 「区域◯◯と紐づけました」と表示され、ダイアログが閉じます。

すでにほかのポリゴンが紐づいている区域は薄い表示になりますが、その行の右にある「飛地ポリゴンを追加」ボタンを押すと、その区域に追加で紐づけられます。1 つの区域が離れた複数の範囲に分かれているとき（飛地）に使います。そのポリゴン自身がすでに紐づいている区域には、このボタンは出ません（「このポリゴンに紐づけ済み」）。

逆に、1 つのポリゴンに複数の区域を紐づけることもできます。戸数の多い大きな建物 1 棟を複数の区域で分担するときなどに使います。

{{shot:map-link-area|「紐づける区域を選択」ダイアログ}}

## 紐づけを解除する

ポリゴンの側から外すときは、「ポリゴン」タブの行の ✂（「紐づけ解除」）を押します。

- 紐づいている区域が 1 つのとき … 「区域◯◯との紐づけを解除しますか？」の確認が出ます
- 紐づいている区域が複数のとき … 「紐づけを解除する区域を選択」が開くので、外したい区域の ✂ を押します

どちらの場合も外れるのは、そのポリゴンとその区域の組だけです。同じ区域に紐づいているほかのポリゴン（飛地）はそのまま残ります。

区域の側からまとめて外すときは、「区域」タブで区域行の ⋯ を押して「ポリゴン紐づけ解除」を選びます。その区域に紐づくポリゴンをすべて外します。複数あるときは「区域◯◯との紐づけ（ポリゴン N 件）をすべて解除しますか？」と件数が示されます。

## 表示・ロック・削除

「ポリゴン」タブの各行には次のボタンが並びます。

- 👁 / — … 「非表示」「表示」。地図に描くかどうかを切り替えます
- 🔒 / 🔓 … 「ロック」「ロック解除」。ロック中は編集も削除もできません
- 🗑 … 「削除」。「このポリゴンを削除しますか？」の確認のあと削除します

一覧上部の 🧹（「不要要素を削除」）は、どのポリゴンにも属さなくなった頂点や辺を取り除きます。

## 区域を追加・整理する

「区域」タブからは、区域親番と区域を編集できます。

- 区域親番行の ✏（「編集」） … 区域親番の名前を変更します
- 区域親番行の ⊕（「子を追加」） … その区域親番の下に区域を 1 つ追加します
- 区域行の 🗑（「削除」） … その区域親番の末尾の区域だけ削除できます。「子要素もすべて削除されますが、削除しますか？」の確認が出ます

削除の直後は一覧の下部に「削除しました」と「元に戻す」「やり直す」が表示され、取り消せます。領域そのものの追加は {{topic:regions}} で行います。区域親番ごとの一覧や状況は {{topic:areas}} で確認できます。

## 訪問記録を開く

次のいずれの操作でも、その区域の {{topic:visits}} が開きます。

- 地図上のポリゴンをダブルクリックする
- 「区域」タブの区域行をダブルクリックする
- 「区域」タブの区域行の ⋯ から「訪問記録」を選ぶ

1 つのポリゴンに複数の区域が紐づいているときは、「訪問記録を開く区域を選択」で開きたい区域を選びます。この画面から移動した場合、訪問記録の地図に「← 区域編集に戻る」が表示され、すぐ戻れます。

## 地図に重なる灰色の点

地図を拡大すると、登録済みの場所が灰色の丸と通し番号で重なって表示されます。ポリゴンと場所の位置関係を確かめるための表示で、この画面では読み取り専用です。クリックしても反応しません。

赤みがかった灰色の点は、その場所が所属する区域のどのポリゴンの内側にも入っていないことを示す警告です。ポリゴンの形を直すか、{{topic:visits}} で場所を移動して解消してください。
