{{route:/settings}} は全員が使える画面です。自分の表示名や表示言語を変えるとき、別の端末を追加・整理するとき、使用許諾を読み返すときに開きます。左のメニューの「設定」から入ります。

{{shot:settings-overview|設定画面の全体}}

## 表示名を変える

「プロフィール」の欄で、ほかのメンバーに見えている自分の名前を変えられます。画面には「このグループ内で表示される自分の名前です。サイドバーとメンバー一覧に反映されます」と書かれています。

1. 「表示名」の入力欄を書き換えます。書き換えると「未保存の変更があります」と表示されます。
2. 「保存」を押します。Enter キーでも保存できます。
3. 「保存しました」と表示されれば完了です。

同じグループに同じ名前の人がすでにいる場合は保存できず、「この名前はグループ内で既に使われています」と表示されます。別の名前にしてください。それ以外の理由で保存できなかったときは「表示名の変更に失敗しました」と表示されます。

変えた名前がほかのメンバーの画面に出るまでには、相手の端末とつながるまでの時間差があります。

## 表示言語を変える

「言語」の欄で「日本語」と「English」を選べます。選んだ時点で画面の表示が切り替わります。

## 使用許諾・免責事項を読み返す

「使用許諾・免責事項」の欄には、同意済みのバージョンが「同意済み: 2026-07-17 版」のように表示されます。「全文を表示」を押すと本文がその場に開き、「閉じる」で戻ります。初回に同意した文書と同じものを、いつでも読み返せます。

## 端末を追加する

パソコンとスマートフォンなど、同じ人が複数の端末で使う場合は、新しく ID を作らずにここから追加します。「デバイス」の欄に「この ID にスマホなど別の端末を追加します。追加した端末は同じ ID で動作します」と書かれているとおりです。

1. すでに使っている端末で「この ID に端末を追加」を押します。
2. 「別端末を追加」という画面が開き、QR コードと URL が表示されます。
3. 追加したい端末の OS のカメラアプリでその QR を撮影するか、表示されている URL を追加したい端末のブラウザで開きます。URL は「URL をコピー」で写し取れます。
4. 追加したい端末でアプリが開き、引き継ぎが終わると一覧にその端末が並びます。

{{shot:settings-add-device|「別端末を追加」で表示される QR コードと URL}}

QR と URL には有効期限があり、画面には残り時間が出ます。この画面を開いている間は自動で更新されるため、開いたままにしておけば期限切れを気にする必要はありません（画面にも「この画面を開いている間、QR / URL は自動で更新されます」と書かれています）。閉じたあとで期限が切れたときは、もう一度「この ID に端末を追加」を押して発行し直します。

引き継ぎの手順は {{topic:getting-started}} にもあります。

## 端末の名前を変える

「登録済みデバイス」に、この ID に紐づいている端末が並びます。いま操作している端末には「この端末」と付きます。名前を付けていない端末は「（名称未設定）」と表示されます。

「名称変更」を押すと「デバイス名を変更」の入力欄が開くので、名前を入れて「保存」を押します。「キャンセル」でやめられます。名前はどの端末からでも変更でき、変更はほかの端末にも反映されます。

## 端末を削除する

使わなくなった端末や、間違えて登録した端末は一覧から削除します。「削除」を押すと確認が出ます。

削除すると、その端末は次の状態になります。

- この ID から切り離され、データのやり取りの対象から外れます
- **その端末に入っているアプリのデータが初期化されます**。ID もグループのデータも消え、最初の画面に戻ります。その端末がオフラインのときは、次にネットワークにつながったタイミングで初期化されます
- 削除を取り消して元に戻すことはできません。同じ端末をまた使いたい場合は、「この ID に端末を追加」からやり直して新しい端末として登録します

確認画面には「このデバイスを削除しますか？削除された端末は初期化されます（オフラインの場合は次回接続時）」と表示されます。実行するなら「削除」、やめるなら「キャンセル」を押します。削除できなかったときは「削除に失敗しました。時間をおいて再度お試しください」と表示されます。

**いま操作している端末（「この端末」と付いている行）は削除できません。** その端末を手放すときは、残しておく別の端末の一覧から削除してください。

削除できるのは自分の端末だけです。ほかのメンバーの端末を削除することはできません。メンバー自体の扱いは {{topic:users}} を参照してください。

## アプリの情報を確認する

画面のいちばん下の「アプリ情報」に、いま読み込まれているアプリのビルド日時とコミットが表示されます。説明のとおり「最新のビルドが読み込まれているかの確認に使えます。古い場合は再読み込みしてください。」という用途です。

不具合を報告するときは、この行の内容を添えると状況が伝わりやすくなります。報告の手順は {{topic:feedback}} にあります。
